Cómo Generar tu Personal Access Token (PAT)

Sigue estos sencillos pasos para crear la llave de acceso en Azure DevOps.

1

Inicia sesión en Azure DevOps

Abre https://dev.azure.com e ingresa con tu cuenta.

2

Abre la Configuración del Usuario

En la esquina superior derecha, haz clic en el icono de User Settings (junto a tu foto) y selecciona Personal access tokens.

3

Crea un Nuevo Token (+ New Token)

Asigna un nombre descriptivo (ej. "Extension Notificaciones Browser") y ajusta la fecha de expiración.

4

Selecciona los Permisos Requeridos

En la sección de Scopes, busca Work Items y marca únicamente la casilla de Read (Lectura).

5

Copia el Token Generado

Haz clic en Create y copia el código alfanumérico generado para pegarlo en la pestaña de Credenciales de esta extensión.
